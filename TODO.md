**Design for this phase (decided by the orchestrator; follow it):**
- New module `src/mediatagger/cheat_sheet.py` (tests in `test_cheat_sheet.py`), the one place the sheet's keys live: `GRID_KEYS`, `VIEWER_KEYS`, `LAUNCH_KEYS`, each a list of `(key, action)` pairs in DESIGN.md's table order. The key text is DESIGN.md's key cell with the backticks removed (`Space / →`, `0–9`, `arrows`, `mouse wheel`); the action is a short version of DESIGN.md's action (one line on a TV). `test_cheat_sheet.py` pins each list's keys, in order, against the key column of DESIGN.md's `### Grid`, `### Viewer` and `### Launch` tables (read from the repo's `DESIGN.md`), so the sheet can't drift from the documented keys. Each item that adds a key list also adds the `h` row (`` `h` `` | show / hide this list of keys) to that DESIGN.md table; the launch screen gets a new key table under `### Launch`: `o` open a folder, `f` fullscreen, `h` keys, `Esc` quit (what the launch screen does today).
- `CheatSheet` (a `QObject` in `cheat_sheet.py`) holds whether the sheet is shown and paints it: `paint(painter, rect, keys)` draws the keys and actions in columns from the top-left of `rect` (a margin of `CORNER_MARGIN`), keys right-aligned in their own column, about 18 px text, in the widget's foreground colour at about 30 % opacity — readable on black, never competing with media (over black its brightest pixel stays well below white). Nothing is drawn while hidden.
- **`h` is caught by the sheet itself**: `CheatSheet.watch(widget)` installs it as an event filter on that widget; a `Key_H` press with no modifiers reaching a watched widget toggles the sheet and is consumed (so the grid's keyboard search never sees it), then repaints that widget (its `viewport()` if it has one). The Window makes one `CheatSheet` and watches the viewer and every grid it builds (folder and results grids). The tag prompt and the search bar are line edits that are never watched, so `h` typed there types an `h`.
- **Painted as the background, beneath everything:** the viewer paints it right after filling black and before drawing the picture (`VIEWER_KEYS` when an item is shown, `LAUNCH_KEYS` when `slideshow is None`, which is the launch screen and the "Can't open" screen); over a video the `MpvSurface` covers it, which is accepted. The grid paints it on its viewport before the tiles (override `paintEvent`, paint on `self.viewport()`, then `super().paintEvent`), fixed to the viewport, not scrolling with the tiles (a scroll must repaint the whole viewport, not blit a moved copy of the sheet). Grid and Viewer take the sheet as a `cheat_sheet=` constructor argument; given none, they make their own hidden one.
- **Remembered:** `state.py` gains `remember_cheat_sheet(state, shown)` / `remembered_cheat_sheet(state)` (key `"cheat_sheet"`, default hidden), writing like `remember_geometry` (an `OSError` is swallowed). The Window reads it when it starts and writes it on every toggle, only when `_may_write_state()` says yes.
